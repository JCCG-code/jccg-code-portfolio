## Verificación End-to-End

### Pre-Launch Checklist

**Funcionalidad:**

- [ ] Todas las secciones visibles y funcionando
- [ ] Navegación smooth scroll funciona
- [ ] Sección activa highlighted en nav
- [ ] Theme toggle persiste preferencia
- [ ] Locale toggle cambia todo el contenido
- [ ] Project cards clickeables
- [ ] Case study pages cargan correctamente
- [ ] Links externos abren en nueva pestaña
- [ ] Email links funcionan

**Performance:**

- [ ] Lighthouse score 90+ (Performance)
- [ ] Todas las imágenes lazy-loaded (excepto hero)
- [ ] Imágenes optimizadas (WebP, tamaños correctos)
- [ ] No layout shift (CLS < 0.1)
- [ ] Fast FCP (< 1.5s)
- [ ] Bundle size razonable (< 200kb JS)

**Responsive:**

- [ ] Layout mobile funciona (320px+)
- [ ] Layout tablet funciona
- [ ] Layout desktop funciona
- [ ] Touch targets adecuados (44px+)
- [ ] No horizontal scroll no deseado
- [ ] Hamburger menu funciona en mobile

**Accesibilidad:**

- [ ] Todas las imágenes con alt text
- [ ] HTML semántico (header, nav, main, section)
- [ ] ARIA labels en botones
- [ ] Navegación por teclado funciona
- [ ] Focus indicators visibles
- [ ] Contraste de color pasa WCAG AA

**i18n:**

- [ ] Todos los textos traducidos (EN + ES)
- [ ] Language toggle actualiza todo
- [ ] No strings hardcodeados
- [ ] Fallback a inglés funciona

**Contenido:**

- [ ] No placeholders "Lorem ipsum"
- [ ] Datos reales de proyectos con métricas
- [ ] Grammar/spelling revisado
- [ ] Copy enfocado en impacto
- [ ] CTAs claros y accionables

**SEO:**

- [ ] Meta title y description
- [ ] Open Graph tags
- [ ] Favicon en lugar
- [ ] Sitemap generado
- [ ] robots.txt configurado

**Code Quality:**

- [ ] No errores TypeScript (`pnpm typecheck`)
- [ ] No errores ESLint (`pnpm lint`)
- [ ] Código formateado (`pnpm format`)
- [ ] No console.log en producción
- [ ] Componentes documentados (TSDoc)
